# ONEALS FIIT booking page

The page clients open from Instagram to book a session. They pick a session, day and time,
and it opens WhatsApp with the booking filled in. No server and no database: everything is in `index.html`.

The FIIT Check-In app on O'Neal's phone makes this page (Booking page > Publish) from its sessions and times,
and greys out times that are already full. Booking messages are pasted or shared into the app.
